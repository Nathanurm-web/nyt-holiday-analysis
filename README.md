# nyt-holiday-analysis# New York Times Holiday Analysis

## Overview

Developed a Python application using the New York Times Article Search API to analyze holiday-related article coverage from 2020–2025.

## Skills Demonstrated

- Python programming
- REST API integration
- JSON data processing
- Data transformation
- Data analysis

## Tools Used

- Python
- New York Times Article Search API
- JSON
- CSV

## Project Goal

Determine which major holiday received the most New York Times coverage each year from 2020–2025.

## Key Features

- Retrieved article data using the NYT Article Search API
- Processed and transformed JSON responses into structured datasets
- Implemented caching and rate-limit handling
- Generated yearly holiday coverage reports
- Exported results to CSV files for analysis

## Results

The project compared article coverage across multiple holidays and identified the most-covered holiday each year between 2020 and 2025.

## What I Learned

- Working with REST APIs
- Handling API rate limits
- Transforming raw data into reports
- Organizing Python projects for repeatable analysis
